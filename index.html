    Dowser

    Finds forgotten oil wells on 1950s survey maps.

    Role
    Machine-learning pipeline (team project)
    Stack
    Python, YOLO11n, GeoTIFF map tiles
    Result
    Validation F1 0.60 → 0.80, recall 0.90
    When
    Cal Hacks 13.0, October 2026

    Abandoned wells leak methane, and many were never recorded. I tiled 1954 USGS maps of Kern County, labelled well symbols by hand and fine-tuned the detector. Detections are leads for field crews, not verified wells.

    Schrödinger's Chess

    Chess where the rules change every turn, against an AI that has to learn them.

    Role
    Game and learning agent
    Stack
    Plain JavaScript modules, no dependencies
    Result
    Rule accuracy climbs from 50% to 85–98% within one game
    When
    Hackathon, theme “Impractical Inventions”

    Each turn every piece gets a random way of moving, and you win by capturing a secret piece. Symmetry lets the agent learn fast: one observed jump teaches all eight of its rotations. It spends a few yes-or-no questions per turn where it is least certain.
